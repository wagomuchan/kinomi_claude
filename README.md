# 木の実をあげよう

森のどうぶつたちに、ほしがっている木の実をあげるブラウザゲームです。スマホのブラウザで遊べます。

## あそびかた

- 木になっている木の実（リンゴ・バナナ・ブドウ）を指でもって、どうぶつのところまで運ぶ
- どうぶつは吹き出しで、ほしい木の実を見せてくれる
- 正しい木の実をあげると +1。違う木の実は受け取ってもらえない
- あげるほど、どうぶつが待てる時間が短くなり、同時に来るどうぶつも増える
- 3回待たせすぎるとおしまい。ベスト記録はスマホの中に保存される

## ファイル

| ファイル | 内容 |
|---|---|
| `index.html` / `style.css` | 画面（タイトル・結果など） |
| `js/game.js` | ゲームの進行・操作・描画。**難しさは先頭の `DIFFICULTY` で調整できる** |
| `js/art.js` | どうぶつ・木の実・背景の絵 |
| `js/crayon.js` | クレヨン風に描くための道具 |
| `js/sound.js` | 効果音（その場で合成） |
| `js/storage.js` | ベスト記録・音の設定の保存 |

## 手元で動かす

ES モジュールを使っているので、ファイルを直接開くのではなく簡単なサーバー経由で開く。

```sh
python3 -m http.server 8000
# → http://localhost:8000/ を開く
```

## 公開（GitHub Pages）

リポジトリの **Settings → Pages** で、Source を「Deploy from a branch」、ブランチを公開したいブランチ・フォルダを `/ (root)` にして保存する。
数分後に `https://wagomuchan.github.io/kinomi_claude/` で遊べるようになる。
